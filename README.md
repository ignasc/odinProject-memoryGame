# Odin Project - Memory card game

A simple game where you must NOT click on the same card more than once.

Live preview: [link](https://ignasc.github.io/odinProject-memoryGame/)

## Features

- 20 cards total, only 10 are shown at once.
- Dark and light theme.

## Tech stack

- HTML
- CSS
- React
- PokeAPI (using pokenode-ts wrapper)

## Learning experience

- Practice using async functions.
- Practice using react features useState, useEffect, useRef.
- Using API through a node wrapper

## Future idea

- Ability to load random cards from a full collection instead of first 20.
